# 台灣十六張麻將實作範圍

`CrestMahjong` 的第一個正式規則集是四人台灣十六張麻將。日本麻將不混入同一套狀態機，日後若需要會以另一個規則集實作。

## 已完成的規則核心

- 144 張牌：萬、筒、條、風牌、三元牌與八張花牌
- 每張實體牌都有唯一 ID
- 可重現的洗牌與牌牆頭尾摸牌
- 手牌、花牌與吃／碰／槓面子資料模型
- 五組面子加一對將的標準胡牌判定
- 公開一組以上面子時的剩餘手牌胡牌判定
- 阻擋花牌、第五張同牌及日本麻將 14 張結構的錯誤胡牌
- 宣告優先權：胡 > 碰／槓 > 吃
- 只有打牌者的下家可以吃
- 可設定一炮多響或只取最近順位
- 四家發牌、莊家十七張與其他玩家十六張
- 初始花牌自動從牌尾連續補牌

## 下一個里程碑

1. 摸牌、打牌與宣告等待視窗狀態機。
2. 吃、碰、明槓、暗槓、加槓及搶槓。
3. 將狀態機接上世界內 `PhysicalTable`。

## 尚未完成

- 台數計算與各地規則選項
- 天胡、地胡、八仙過海等特殊結算
- 實體牌桌、私人手牌與動畫
- 房間 GUI、觀戰、機器人與斷線重連

規則核心維持純 Java，不直接依賴 Bukkit 實體，讓規則可以用單元測試驗證，世界渲染故障也不會破壞牌局資料。
